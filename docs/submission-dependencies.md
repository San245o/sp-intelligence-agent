# Submission runtime disclosure

The default `python run.py` pipeline uses deterministic extraction, identity rules and source-backed answers. It invokes no language model. The retained optional Gemini tooling is outside the default run path. Serper Search/News/Places and Tavily basic search are optional credentialed services. The default budget for 1,000 companies is 500 provider credits shared across keys and categories; a public checkout contains no credential and uses free fallback unless the evaluator supplies `SERPER_API_KEY` (or another supported environment variable).

Sources include Brønnøysund registry/accounting endpoints and public bulk data, NAV public job feeds, permitted company/publisher pages and public search/feed discovery. Captured source attribution does not transfer source ownership; provider/source terms and robots/rate policies apply. Places aggregates are ratings/review counts; individual review sentiment is not inferred from star ratings.

Direct dependency licence declarations from the reviewed installed distributions: Beautiful Soup and Pydantic: MIT; extruct: BSD; lxml, tldextract and pypdf: BSD-3-Clause; trafilatura and google-genai: Apache-2.0; NumPy: BSD-3-Clause with bundled component notices (0BSD/MIT/Zlib/CC0-1.0). Preserve each distribution's licence files. The repository currently does not declare a separate source-code licence. `requirements-lock.txt` pins the reviewed dependency closure.

Cost: no LLM cost for the default run. At Serper's advertised Starter top-up price of $1 per 1,000 credits, a 500-credit run corresponds to at most $0.50 in Serper query value before taxes (excluding infrastructure). Free promotional credits may reduce cash cost to zero. This is not the minimum top-up purchase price. Other provider plans differ; Tavily fallback requires its own credential and pricing. Set `SERPER_USD_PER_CREDIT` only to the actual applicable rate. Price reference: https://serper.dev/ (checked 2026-11-06).
