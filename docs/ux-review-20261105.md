# UX review — 5 November 2026

The existing dashboard had working company search, company switching and sourced research responses, but its static masthead and LinkedIn-only counters contradicted current data. It also omitted publication dates stored under observation metrics, and its activity answer listed headlines without answering the latest-date question. The large hero delayed access to the workspace.

The separate `ui/research` assets reuse the existing dashboard renderers. They derive summaries from accepted observations, count verified website URLs, surface publication dates, label company-published versus independent news, add evidence filters/sorting, reduce the hero, and give the latest supported publication date in activity answers. Source inspection includes URL, acquisition time and SHA-256. Missing evidence remains explicitly unknown.

Browser checks against the saved 100-company recovery fixture verified: 12 verified website URLs, 7 companies with verified social links and 44 activity records; news filtering returns exactly four companies; selecting Solid Sikring returns its 12 captured items with latest supported date 2026-10-25; the source disclosure exposes the matching URL and source hash; no browser console errors were observed. This is interface verification, not a discovery comparison or an independent UX score.

UI assets are prepared separately while acquisition code remains frozen. The final generator integration and repeat checks occur before delivery. Mobile/responsive and export/resume verification are still to be completed before claiming those flows pass.

Final integrated browser recheck on 6 November: publication-only questions route to dated activity; filtered export downloads successfully; company pin survives reload and was then removed from the test workspace; mobile layout at requested 390px viewport has 375px content/client width with no horizontal overflow; no browser console errors observed. The actual generated HTML includes all UX assets inline and passes checks for three JavaScript blocks. Saved named-view creation was not exercised.
